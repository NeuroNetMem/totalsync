TotalSync is a low-cost, open-source teensy-based synchronization system. This system is composed of a teensy 4.1 coupled with a web based python interface and creates a data-file saving 42 analog/digital channels plus 8 long variables capable of stocking more complex data at a rate of 1kHz. This allows for a user friendly experience with a full control of all hardware or triggers used in the setup. We created this synchronization system to be adaptable and inexpensive, also TotalSync can synchronize a number of modules of your choice.
To show is adaptability we tested it with a combination of a head-fixed virtual and recording technique.
So far the recording techniques used are:
 * A 2-photon microscope
 * A voltage sensitive microscope
 * Electrophysiology/Neuropixel
In this github you will find all the code needed to run TotalSync but also all the used case previously cited.
