# API reference

`totalsync-utils` and `totalsync-2p` are importable libraries as well as command-line
tools; this section documents their public interfaces, generated from the docstrings.

Each page lists the names the package exports through `__all__` — the ones covered by the
usual expectation that they will not change shape without a version bump. Anything not
listed here is internal and may move.

`totalsync-webinterface` is not documented here. It is an application rather than a
library, and its interface is the `totalsync` command: see {doc}`../totalsync`.
